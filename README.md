# Lumencatholic

Crie o Lumen, um site responsivo para aprender a fé católica por meio de lições interativas e curtas, inspirado na dinâmica de apps educativos como Duolingo, mas com identidade própria.



Visual: estilo 2D, minimalista, cantos arredondados e animações suaves. Use grená "#641C32", grená secundário "#7B293F", creme "#F8F1E2", cartões "#FFF9ED" e dourado "#F2BE50". Botões com efeito elevado em 2D.



Mascote: use a imagem anexada como referência oficial. Preserve sua identidade visual, sem redesenhá-lo.



Boas-vindas e cadastro: crie telas com navegação funcional para:



1. Boas-vindas.

2. Como conheceu o Lumen?

3. Nível de conhecimento da fé.

4. Sacramentos recebidos, com seleção múltipla.

5. Tema de interesse: Bíblia, Jesus, sacramentos, orações, Igreja ou começar do zero.

6. Perfil com nome/apelido e senha de pelo menos 8 caracteres, sem pedir e-mail ou telefone.



Permita voltar às etapas sem perder as respostas. Nenhuma escolha deve bloquear conteúdos.



Tela principal: mostrar a próxima lição pelo nome, como “O que é a Bíblia?”, além de XP, progresso e trilha de estudos. Criar navegação para Início, Trilha, Biblioteca e Perfil.



Lições: comece com “Fundamentos da fé católica” e estas aulas:



- O que é a Bíblia?

- Quem é Jesus Cristo?

- O que é o Credo?

- O que é a Igreja Católica?

- Como funciona a oração?

- O que são os sacramentos?



Cada lição deve ter explicação simples, perguntas interativas, correção das respostas e conclusão com XP.



Animações: transições suaves, botões que afundam ao clicar, progresso animado e pequenas celebrações ao concluir aulas. Priorize bom desempenho em celulares.



Importante: desenvolva em etapas, começando apenas pela identidade visual e tela de boas-vindas. Não tente construir tudo de uma vez. Preserve o código existente e verifique se tudo funciona antes de avançar. Use React, TypeScript e Tailwind conforme a estrutura atual do projeto.
